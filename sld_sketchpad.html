How to fill the table — every column, every type, the wiring recipes, and the words that change a symbol

The idea

One row per item, top of the network first. The drawing's topology comes only from ID and Feeds from: an item is drawn under whatever it feeds from. Row order sets left-to-right order. A half-filled row still draws, with an open terminal where the supply or the load is missing, and the problems box above the drawing tells you which row to complete.

Getting it out

Three files, each written from the table, not copied off the screen. Download PDF saves one A3 landscape page: the sketch with the equipment table beside it or under it, whichever leaves the drawing bigger — the sheet to send or print. Download SVG saves the drawing itself, to open in a browser or a drawing tool. Download DXF saves an R12 DXF with the sketch and, to its right, the equipment table, centred so it opens in the middle of any CAD window. Survey info

Equipment — one row per item, top of the network first

ID Type Description Rating Voltage Protection Feeds from Notes
Feeds from = the ID of the item supplying this one (pick from the list); comma for two supplies (bus tie: BB1, BB2 — ring RMU: RMU1, RMU2). Protection = the device on this item's supply side (CB, LBS, Fuse, Fuse-switch, Contactor, Fuse-contactor; blank = the usual default; comma list matches Feeds from). Row order sets left-to-right order. Words like VSD, Spare, N.O. or capacitor in Description / Notes change the symbol — see How to fill. Keys: Enter next row, Alt+↑/↓ move row, Ctrl+Z undo.
